# class-04-legal

Slide deck for the class on the technical and legal framework (Applied Artificial Intelligence in Architecture, FA.ULisboa).

`index.html` is a single self-contained presentation in Portuguese (PT-PT) and English. Use the **PT / EN** button in the bottom bar (or press `L`) to switch language; the current slide is kept.

Navigation: ← / → to move, `F` for full screen, `Ctrl+P` to print one slide per page (current language). Slides 7–11 and 14 include the full prompts in a read-and-copy panel.

Link: https://cfcduarte363.github.io/class-04-legal/ (English directly: add `?lang=en`).
