# class-04-legal

Slide deck for the class on the technical and legal framework (Applied Artificial Intelligence in Architecture, FA.ULisboa).

| Language | File |
| --- | --- |
| Português (PT-PT) | `class-04-slidedeck_pt.html` |
| English | `class-04-slidedeck_en.html` |

Each file is a single self-contained HTML presentation (fonts embedded, works offline). Open it in a browser; navigate with ← / →, press `F` for full screen, `Ctrl+P` to print one slide per page. Slides 7–11 and 14 include the full prompts in a read-and-copy panel.

The English version is a translation of the Portuguese original. Portuguese legal instruments (PDM, RJUE, RGEU, SCE, Decreto-Lei titles) keep their official names; in the references, English glosses are added in square brackets.
